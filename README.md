# Budget App 2

A clean workspace for building the next version of the Budget App.

## Project status

This repository is in the planning and setup phase. Product decisions, architecture notes, and milestones belong in [`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md).

## Repository layout

```text
.
|-- docs/              Project plans and technical notes
|-- .editorconfig      Shared editor defaults
|-- .gitignore         Files that should stay local
|-- CONTRIBUTING.md    Branch, commit, and review workflow
`-- README.md          Project overview
```

Application and test directories will be added once the technology stack is selected, so the repository does not lock the project into a framework prematurely.

## Getting started

1. Clone the repository.
2. Read [`docs/PROJECT_PLAN.md`](docs/PROJECT_PLAN.md).
3. Create a short-lived branch from `main`.
4. Keep setup instructions here up to date as the app takes shape.

## Working agreement

- Keep `main` stable.
- Use focused branches and pull requests for changes.
- Never commit credentials, API keys, personal financial data, or local environment files.
- Record meaningful product or architecture decisions in `docs/`.
